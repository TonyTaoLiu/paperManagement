## 决策记录
- llama.cpp 固定 tag `b11721`；源码编译采用可移植 CPU 分发（`GGML_NATIVE=OFF`、`GGML_CPU_ALL_VARIANTS=ON`）——`-march=native` 构建在换机后出现 `Illegal instruction`。
- llama-server 单槽（`-np 1`）：默认 4 槽使 4B 峰值内存 9.6 GB → 5.4 GB。
- FTS5 用 trigram 分词；少于 3 字的查询词退化为 LIKE。
- 归档解析/切分/去重全部规则实现，LLM 只做字段精修；所有 LLM 抽出的实体必须在原文中出现才保留。
- 路由：softmax 温度取 0.02（0.05 时几乎全判"新建类别"；≤0.01 自动归类开始出错）。
- 语义地图用自写 numpy t-SNE，避免 umap-learn/numba 的体积与跨平台风险。
- 默认档位：8 GB = Qwen3.5-4B + EmbeddingGemma-2；16 GB = Qwen3.5-9B + EmbeddingGemma-2。
- OpenAlex 在本沙箱对无 key 请求限流（共享出口额度已用尽），因此元数据补全/OpenAlex 推荐源只用录制样例测试，未做真实联网验证；已支持用户填写 OpenAlex key / 邮箱。
